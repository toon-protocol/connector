Access

Read authority and write authority are different things on this surface (ADR 0008). The bearer token lets this page inspect; only an operator key on the node's write_keys allowlist lets it change anything, and every change it makes is signed here, in your browser, by that key.

Dealing

A forward whose two legs hold different tokens converts at a rate this node has declared (ADR 0071) — never silently, and never at a rate it has not got. A rate is declared in the config file or observed from a pool by this node's own poller; nothing sets one from here, and this table is a read. A pair that is stale or refused rejects every forward across it, and only across it, so an outage no route table can explain shows up here.

Peering

A peering is a counterparty, a carriage, a fee and a cap. Config-file rows are immutable for the process's life; runtime rows are durable and can never take a key the file owns (ADR 0034). A peering's fee changes only by editing the file and restarting.

The node fetches the counterparty's self-description and peers with whoever answers — trust on first use (ADR 0058). A 502 means go and look at that URL.

Routes

Three kinds. A terminated route ends at a handler and carries a price; a peer route forwards to a peering; a leased route is pushed by a controller with a TTL and lapses on its own. Precedence is longest prefix, then rank (ADR 0048).
